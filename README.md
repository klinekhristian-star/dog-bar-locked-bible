# Dog Bar Locked Bible

Photoreal character bible for **Rose**, **Thick Betty**, and **Luna**.

## Routes (full app)

| Path | Character |
|------|-----------|
| `/` | Rose |
| `/betty` | Thick Betty |
| `/luna` | Luna |

## Static one-pager

Open `dog-bar-locked-bible.html` (or rename to `index.html` for static hosting).

## Develop

```bash
npm install
npm run dev
```

## Deploy (Vercel)

Import this repo in Vercel. Build: `npm run build`.

# Dog Bar Locked Bible

Photoreal identity locks for **Rose**, **Thick Betty**, **Luna**, and **Summer Wins**.

## Routes

| Path | Character |
|------|-----------|
| `/` | Rose |
| `/betty` | Thick Betty |
| `/luna` | Luna |
| `/summer` | Summer Wins |

## Develop

```bash
npm install
npm run dev
```

## Deploy (Vercel)

Import this repo in [Vercel](https://vercel.com/new). Build command: `npm run build`.
